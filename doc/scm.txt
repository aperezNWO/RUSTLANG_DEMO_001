# Build Docker image
docker build -t rust-ping-api .

# Run Docker container
docker run -d -p 8080:8080 --name rust-service rust-ping-api

# Test service endpoint
curl http://localhost:8080/ping

////////////////////////////////////////////////

Production Deployment Options

Docker Cloud (Render / Fly.io / AWS ECS): Push the Docker image directly to your container registry and run on port 8080.

Bare Binary Deployment: Copy the single compiled binary (target/release/rust-ping-api) to any Linux server along with SSL certificates (ca-certificates) and run it directly as a systemd service—no external runtime required.
